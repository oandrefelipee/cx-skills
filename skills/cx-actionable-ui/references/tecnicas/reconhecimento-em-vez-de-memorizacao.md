# Reconhecimento em vez de memorização

*Recognition over recall* · Técnica

## Definição

Mostrar opções visíveis em vez de exigir que a pessoa lembre.

## Quando usar

Filtros, busca, seleção de modelo ou fonte de dados.

**Exemplo:** Seletor de modelo com os recentes à vista e o padrão marcado.

## Anti-padrão

Campo livre onde cabia uma lista.

## Antes → depois

```text
Antes
+--------------------------------------+
| Modelo                               |
| [digite o código do modelo___]       |
+--------------------------------------+
Depois
+--------------------------------------+
| Modelo                               |
| (● Padrão) Essencial · Detalhado     |
| [▾ Ver todos os modelos]             |
+--------------------------------------+
```
1. O modelo padrão vem marcado; os recentes ficam à vista.

## Microcopy

- Antes: "Digite o código do modelo"
- Depois: "Padrão · Recentes: Essencial · Detalhado"

## Prompt

> Troque campo de texto livre por seleção com opções visíveis e recentes.

## Fonte
