# Um termo por conceito

*One term per concept* · Técnica

## Definição

Escolha uma palavra para cada ideia e use-a em todo lugar: menu, título, botão, e-mail, documentação. Sinônimos fazem a pessoa achar que são coisas diferentes.

## Quando usar

Todo o produto; glossário compartilhado entre design, texto e código.

**Exemplo:** `Pedidos` na navegação, no título e no botão `Ver pedidos`.

## Anti-padrão

`Pedidos`, `Ordens` e `Compras` para a mesma coisa.

## Antes → depois

```text
Antes
+--------------------------------------+
| Menu: Ordens                         |
| Título: Suas compras                 |
| [ Ver pedidos ]                      |
+--------------------------------------+
Depois
+--------------------------------------+
| Menu: Pedidos                        |
| Título: Pedidos                      |
| [ Ver pedidos ]                      |
+--------------------------------------+
```

## Microcopy

- Antes: "Ordens / Suas compras / Ver pedidos"
- Depois: "Pedidos / Pedidos / Ver pedidos"

## Prompt

> Use um termo por conceito em toda a interface; liste os sinônimos a eliminar.
