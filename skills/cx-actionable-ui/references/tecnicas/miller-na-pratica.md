# Lei de Miller

*Miller's Law* · Técnica

## Definição

A memória de trabalho segura cerca de 7 itens.

## Quando usar

Agrupar métricas e menus.

**Exemplo:** Métricas em 3 grupos com título curto.

## Anti-padrão

Doze métricas iguais numa lista corrida.

## Antes → depois

```text
Antes
+--------------------------------------+
| Taxas: A · B · C · D · E · F · G ·   |
| H · I · J · K · L                    |
+--------------------------------------+
Depois
+--------------------------------------+
| Entrega                              |
| A · B · C                            |
| Prazo                                |
| D · E · F                            |
| Contato                              |
| G · H · I                            |
+--------------------------------------+
```

## Microcopy

- Antes: "Taxa A · B · C · D · E · F · G · H · I · J · K · L"
- Depois: "Entrega · Prazo · Contato"

## Prompt

> Agrupe em blocos de até 5-7 itens com título curto.
