# Mostrar, não explicar

*Show, don't tell* · Técnica

## Definição

Trocar a instrução por um exemplo ou preview vivo.

## Quando usar

Onboarding, vazios.

**Exemplo:** Preview da página pública em vez do texto explicando como ela fica.

## Anti-padrão

Parágrafo que um preview resolveria.

## Antes → depois

```text
Antes
+--------------------------------------+
| A página mostra ao cliente o mapa,   |
| as etapas e a previsão de entrega    |
| com as cores da sua loja, e o        |
| cliente acompanha sem ligar.         |
+--------------------------------------+
Depois
+--------------------------------------+
| Veja como o cliente verá             |
| +--------------------+               |
| | ▒▒▒ <logo da loja> |               |
| | (● Em trânsito)    |               |
| +--------------------+               |
+--------------------------------------+
```
1. ▒▒▒ é a prévia viva da página, com a marca da loja.

## Microcopy

- Antes: "A página mostra o mapa, as etapas e a previsão com as cores da sua loja"
- Depois: "Veja como o cliente verá"

## Prompt

> Troque a explicação por um exemplo vivo ou preview; no máximo 1 linha de apoio.
