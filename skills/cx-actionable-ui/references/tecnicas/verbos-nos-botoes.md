# Verbos nos botões

*Action verbs on buttons* · Técnica

## Definição

Verbo + objeto, até 3 palavras; o destrutivo nomeia o objeto.

## Quando usar

Todo botão.

**Exemplo:** `Excluir domínio` no lugar de `OK`.

## Anti-padrão

"OK", "Enviar", "Continuar", "Clique aqui".

## Antes → depois

```text
Antes
+--------------------------------------+
| Excluir este domínio?                |
| [ OK ] [ Enviar ]                    |
+--------------------------------------+
Depois
+--------------------------------------+
| Excluir este domínio?                |
| [ Cancelar ] [■ Excluir domínio]     |
+--------------------------------------+
```

## Microcopy

- Antes: "OK / Enviar"
- Depois: "Excluir domínio / Ligar e-mails"

## Prompt

> Todo botão: verbo + objeto, máx. 3 palavras; destrutivo nomeia o que será excluído.
