# Informação à frente

*Front-loading* · Técnica

## Definição

A palavra-chave nas primeiras palavras.

## Quando usar

Títulos, botões, mensagens.

**Exemplo:** `Sem créditos: pedidos aguardam`.

## Anti-padrão

"Você pode, a qualquer momento, adicionar…".

## Antes → depois

```text
Antes
+--------------------------------------+
| Os novos pedidos esperam até você    |
| solicitar mais créditos              |
+--------------------------------------+
Depois
+--------------------------------------+
| Sem créditos. Pedidos aguardam.      |
| [■ Comprar créditos]                 |
+--------------------------------------+
```

## Microcopy

- Antes: "Os novos pedidos esperam até você solicitar mais créditos"
- Depois: "Sem créditos. Pedidos aguardam."

## Prompt

> Reescreva cada frase com a informação-chave nas 3 primeiras palavras.
