# Efeito Von Restorff (isolamento)

*Von Restorff Effect (Isolation Effect)* · Lei

## Definição

Entre itens parecidos, o que é diferente é o que se lembra. Use contraste para o que importa, e só nele.

## Quando usar

Planos, CTAs, avisos importantes, item recomendado.

**Exemplo:** Um plano marcado `Recomendado` com cor de destaque entre três planos neutros.

## Anti-padrão

Destacar tudo: quando tudo grita, nada se destaca.

## Antes → depois

```text
Antes
+--------------------------------------+
| [■ Básico] [■ Pro] [■ Empresa]       |
+--------------------------------------+
Depois
+--------------------------------------+
|             (● Recomendado)          |
| [ Básico ]  [■ Pro ]  [ Empresa ]    |
+--------------------------------------+
```

## Microcopy

- Antes: "Básico · Pro · Empresa (todos iguais)"
- Depois: "Pro · Recomendado"

## Prompt

> Destaque apenas um item (o recomendado) e deixe os demais neutros.
