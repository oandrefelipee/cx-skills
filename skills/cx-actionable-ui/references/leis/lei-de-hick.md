# Lei de Hick

*Hick's Law (Hick–Hyman)* · Lei

## Definição

O tempo para decidir cresce com o número e a complexidade das opções. Menos escolhas à vista, decisão mais rápida.

## Quando usar

Menus, barras de ação, onboarding, planos e preços.

**Exemplo:** Menu da conta com 5 itens e `Mais` para o resto, em vez de 14 links.

## Anti-padrão

Seis botões de peso igual lado a lado.

## Antes → depois

```text
Antes
+--------------------------------------+
| Conta                                |
| [Perfil] [Faturas] [Equipe] [API]    |
| [Webhooks] [Logs] [Tema] [Ajuda]     |
+--------------------------------------+
Depois
+--------------------------------------+
| Conta                                |
| [Perfil] [Faturas] [Equipe] [Mais ▾] |
+--------------------------------------+
```

## Microcopy

- Antes: "Escolha uma das opções abaixo para continuar"
- Depois: "Perfil · Faturas · Equipe · Mais"

## Prompt

> Reduza as escolhas à vista: 4-5 opções e o resto agrupado em 'Mais'.
