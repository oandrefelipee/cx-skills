# Infisical

Categoria: segredos · Estado: esboço

- O cofre é a fonte; o provedor de deploy recebe por integração ou por `infisical run -- <comando>` no início do processo.
- Um ambiente por estágio (dev, staging, produção); nunca o mesmo valor em dois.
- Autohospedado: o painel fica atrás de VPN; backup do banco do cofre e da chave de criptografia, separados.
- O agente lista nomes de segredos, nunca valores.
