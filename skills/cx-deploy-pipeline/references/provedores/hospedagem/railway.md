# Railway

Categoria: hospedagem · Estado: esboço

| Campo | Como fazer |
|---|---|
| `deploy.run` | auto-deploy da branch ligada ao ambiente; ou `railway up` |
| `deploy.status` / `deploy.logs` | `railway status`, `railway logs` |
| `deploy.rollback` | "Rollback" de um deploy anterior no painel |
| health | health check path por serviço |

Armadilhas: ambientes (`production`, `staging`) têm variáveis próprias; confira o ambiente ativo da CLI antes de qualquer comando.
